# contest-hub 작업 기록

공모전 일정 + 프로젝트 진행상황(칸반) + GitHub 연동 개인 공개 사이트. Vercel 배포.
설계: `docs/superpowers/specs/2026-11-06-contest-site-design.md`

## 결정 사항 (2026-11-06)
- 데이터 입력: 사용자가 채팅으로 알려주면 Claude가 `data/contests.ts` 수정 → push → Vercel 자동 배포. DB·관리자 화면 없음.
- 공개 사이트(포트폴리오 겸용).
- 진행상황: 공모전 일정 + 칸반 + GitHub 연동.
- 스택: Next.js(App Router) + 데이터 파일 + GitHub API ISR(1시간).
- GitHub 저장소 이름: `contest-hub` (계정 SilVerBell0109).
- 시작 데이터: 사용자가 준 실제 참여 대회 4개만 넣음(가짜 예시는 공개 사이트에서 오해 소지라 제외).
